# Build a Professional Journalist Portfolio — SPA

I want you to build a **modern, professional, visually impressive Single Page Application (SPA) portfolio website for a female journalist**.

The portfolio should strongly reflect her personality as a **bold, confident, fearless, intelligent, and professional woman journalist**. The design should feel like a serious journalist's personal brand rather than a generic developer portfolio.

## 1. Technology Requirements

Use ONLY the following technologies:

* HTML5
* CSS3
* Bootstrap 5
* Vanilla JavaScript
* Three.js for background animations

Do NOT use:

* React
* Angular
* Vue
* Tailwind CSS
* jQuery
* Any frontend framework

The application should be a clean **SPA**, where navigation between sections happens smoothly without reloading the page.

Organize the project properly, for example:

```text
portfolio/
│
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── assets/
│   ├── images/
│   ├── icons/
│   └── resume/
│       └── resume.pdf
└── README.md
```

Keep the code clean, modular, readable, and easy to maintain.

---

# 2. Overall Design

Create a **dark-themed editorial/journalism-inspired portfolio**.

### Primary design direction

* Dark background
* Black / very dark charcoal as the primary background
* White/light text
* Use **red as the accent color**
* Red should be used strategically for:

  * headings
  * highlights
  * buttons
  * active navigation
  * article category/tag
  * important text
  * timeline highlights
  * hover effects

Do not overuse red.

The overall visual identity should communicate:

> **Bold. Fearless. Investigative. Professional.**

Avoid making it look like a generic corporate portfolio.

Use modern typography with strong headings and excellent readability.

# 9. Article Data Structure

Make articles easy to add later.

Store article information in a JavaScript array/object rather than hardcoding every card directly into HTML.

Example structure:

```javascript
const articles = [
    {
        title: "Article Title",
        description: "Short description...",
        image: "assets/images/article1.jpg",
        category: "Investigative Journalism",
        publication: "Publication Name",
        date: "August 2026",
        link: "https://example.com/article"
    }
];
```

Then dynamically generate article cards using JavaScript.

This will make the portfolio easy to maintain.

Include several sample articles as placeholders.

## Send Me a Message Form

Create a professional contact form with:

* Name
* Email
* Subject
* Message
* Send Message button

Example:

```text
Name
[________________________]

Email
[________________________]

Subject
[________________________]

Message
[________________________]

[ SEND MESSAGE ]
```

Since this is a static SPA, implement the email interaction using:

```html
<a href="mailto:name@gmail.com">name@gmail.com</a>
```

For the form, use JavaScript to construct a `mailto:` link containing:

* sender name
* sender email
* subject
* message

Then open the user's default email application.

Do NOT pretend that the form sends emails through a backend.

Clearly make it a client-side mailto implementation.
